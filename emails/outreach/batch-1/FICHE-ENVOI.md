# Batch 1 — Fiche d'envoi

## Méthode d'envoi

Pour chaque fichier ci-dessous :
1. **Double-clic** sur le fichier `.html` → il s'ouvre dans ton navigateur
2. **Ctrl+A** (tout sélectionner) → **Ctrl+C** (copier)
3. **Gmail** → Nouveau message → **Ctrl+V** (coller dans le corps)
4. **Ajouter** le destinataire et l'objet indiqué ci-dessous
5. **Envoyer**
